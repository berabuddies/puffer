# Env Var Registry Test Split

## Design

- Keep `puffer_config::env_vars::ALL_ENV_VARS` and `EnvVar` unchanged.
- Move private unit tests from `src/env_vars.rs` to `src/env_vars/tests.rs`
  using Rust's sibling module convention.

## Architecture

- `env_vars.rs` remains the public registry module and declares
  `#[cfg(test)] mod tests;`.
- `env_vars/tests.rs` owns only test-only validation for uniqueness,
  descriptions, and env var name shape.

## Logic

- Runtime behavior is unchanged.
- Test coverage is unchanged; the same assertions still run under
  `cargo test -p puffer-config`.

## Contracts

- Public Rust API remains stable.
- The env var registry stays under the repository's 1000-line source file
  limit without hiding registry data behind a different public path.

## Compatibility

- No configuration format or runtime compatibility impact.
- Existing imports of `puffer_config::env_vars::{ALL_ENV_VARS, EnvVar}` remain
  valid.
