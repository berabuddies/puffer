# Connector Catalog Count Refresh

The workflow connector catalog assertions now track the current built-in
connector surface of 15 templates. The catalog includes Telegram, Discord,
Matrix, Slack, Email, Gmail, Google Calendar, Lark, Feishu, and WeChat entries.

Action-capable filtering expects 12 of those 15 templates to advertise actions;
the no-action templates remain `discord-bot`, `matrix-bot`, and `slack-bot`.
Serve filtering still returns the three bot connectors intended for `puffer
serve`: `telegram-bot`, `discord-bot`, and `matrix-bot`.

The update is test-only and does not change connector command rendering,
resource loading, workflow trigger eligibility, or HTTP ingress exclusion.

The OpenAI Responses skill-action-obligation E2E fixtures also force SSE
transport under the shared runtime environment lock. This keeps the scripted
HTTP mock sequence independent from WebSocket transport tests that temporarily
enable `PUFFER_OPENAI_WEBSOCKET` in parallel test runs, while preserving and
restoring the caller's original environment value after each test.
