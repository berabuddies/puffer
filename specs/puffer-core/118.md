# Workflow action pause and resume commands

- `/workflows pause <binding-slug>` and `/workflows resume <binding-slug>`
  now update workflow action binding status through the subscription manager's
  typed `WorkflowBindingStore::set_status` API.
- `/workflows disable <binding-slug>` aliases pause and
  `/workflows enable <binding-slug>` aliases resume; command output reports the
  resulting `enabled` or `paused` status.
- Toggling a workflow action refreshes connection consumers immediately, so
  connector streams start or stop according to the binding's new status.
- `/workflows actions` now surfaces contextual `pause=` or `resume=` commands
  beside `delete=`, and action search terms include the management commands.
