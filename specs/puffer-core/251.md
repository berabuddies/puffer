# Monitor Task Description Preview Rules

## Summary

The command-helper monitor prompt mirrors the daemon prompt's content-first `TaskCreate.description` rules. This keeps monitor tasks created through older command-helper flows aligned with the daemon behavior.

## Behavior

- Do not put source-first prefixes in task descriptions.
- Use the core error for clear error messages.
- Use question intent for questions.
- Use requested action for requests.
- Use the original content's first 20 characters for casual or incomplete content that still requires a task.
- Keep source information in metadata.

## Compatibility

This is a prompt-only contract change. Stored tasks keep their current descriptions until a future task update rewrites them.

## Verification

`command_helpers::monitor::tests::monitor_prompt_constrains_task_description_previews` asserts that the command-helper prompt contains the same source-prefix and preview rules as the daemon prompt.
