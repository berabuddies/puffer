# Monitor Rule Section Naming

## Design

The Tasks settings Rules tab labels the monitor condition section as `Filter
rules` instead of `Ignore rules`. The label describes both include and skip
conditions while avoiding a misleading ignore-only name.

## Compatibility

- This is a Desktop UI label change only.
- Workflow snapshots, daemon requests, and subscription storage continue to use
  the existing `ignore_filters` field for skip rules.
- Monitor rule add/delete request modes remain `include` and `exclude`.
