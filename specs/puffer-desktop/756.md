# Monitor Rule Field Options

## Design

The monitor rule condition builder renders connector-specific field choices as
plain `Message detail` options directly after `Message text`. It does not use
an option group label, so field choices are not visually indented.

## Compatibility

- This is a Desktop UI structure change only.
- Internal schema names, request payloads, and `monitor_rule_schema.fields`
  remain unchanged.
- Message text keyword rules remain the first option.
