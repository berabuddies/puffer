# Monitor Message Text Operator Requests

The task monitor rule editor now sends the selected condition operator for
`Message text` rules.

- Keyword rule requests include `operator`, defaulting to `contains` in the API
  helper for compatibility.
- The rule editor passes the current condition selector for Event.text, so
  `contains`, `is`, and `matches regex` map to the daemon rather than being
  flattened to keyword contains.

Payload field rules continue to send `field`, `operator`, and `value` from
connector schema metadata.
