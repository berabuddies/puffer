# Monitor Task Display Sanitization

Tasks screen monitor rows and selected-task details sanitize monitor-generated
subject and description text before rendering. The UI removes source transport
terms and triage judgment boilerplate such as Telegram, message asks,
actionable request, and Need a reply, and prefers the quoted original message
when the description includes one.

This is a display-layer fallback for stale snapshots or older daemons. Source
metadata remains available through task context fields and is not folded into
the visible description.
