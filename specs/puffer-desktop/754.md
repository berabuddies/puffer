# Monitor Rule Pill Colors

## Design

Monitor rule condition pills use field-aware tones so users can scan mixed
payload conditions quickly. `Message text` keeps a dedicated text tone because
it always maps to `Event.text`. Connector payload fields receive tones from the
selected monitor schema order.

## Behavior

- All keyword rules that target `Message text` share the same text tone.
- Payload field rules use the tone assigned to their schema field.
- Fields in the same schema receive distinct tones for the first 20 payload
  fields, then the palette repeats.
- Unknown payload fields fall back to the first payload tone.
- The tone is exposed through `data-tone` on each condition pill and styled in
  the shared Tasks CSS.
