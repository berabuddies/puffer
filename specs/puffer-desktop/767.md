# Merge PR Integration Fixes

The desktop merge integration keeps two prior contracts intact while adopting
the new onboarding and turn prose behavior.

When the app re-enters onboarding solely because no usable agent provider is
available, the staged first-run flow now opens directly on the provider step.
Explicit forced onboarding still starts at run-mode selection, so the stubbed
flow remains testable without weakening the provider-auth gate used by skip
flags and last-provider logout.

Transcript reload reconciliation now preserves transient message identity and
turn ids when persisted user or assistant messages match local live rows. Live
stream assistant placeholders for a turn are considered settled once the
persisted assistant response for that turn lands, so partial streamed text is
removed instead of surviving next to the final persisted answer.

Playwright coverage follows the provider setup modal and asserts that
turn-tagged assistant prose remains visible in its original assistant row
without being collapsed into an Agent activity group.
