# Monitor Rule List Layout

## Design

Monitor rule conditions render as sorted content-sized pills in a wrapping chip
list instead of full-width rows. The list is capped with vertical scrolling so a
monitor with many include or skip conditions grows predictably without pushing
controls out of alignment.

## Behavior

- Conditions are sorted by their displayed title with locale-aware,
  case-insensitive comparison.
- Each condition pill sizes to its displayed text plus the remove action, while
  still truncating safely if the text is wider than the available space.
- Multiple short condition pills share a row and wrap only when the available
  width runs out.
- The condition builder uses a three-column control grid and a separate action
  row so Cancel and Add condition remain inside the rule group.
- Narrow screens continue to collapse the builder to one column.
