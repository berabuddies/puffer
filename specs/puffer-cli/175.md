# Monitor Task Description Preview Rules

## Summary

Monitor triage prompts now constrain `TaskCreate.description` to be content-first. New monitor-created task descriptions must omit source-first prefixes such as `Telegram message from`, `Incoming Telegram message`, `Telegram user sent`, `In Telegram group`, and `message from chat_id`.

## Behavior

- Clear errors should be summarized by the core error.
- Questions should describe the question intent.
- Requests should describe the requested action.
- Casual or incomplete content that still becomes a task should use the original content's first 20 characters.
- Source information belongs in task metadata, not in `description`.

## Compatibility

The change affects future monitor task creation prompts only. Existing records in `monitor_tasks.json` are not migrated or rewritten.

## Verification

`daemon_workflows::monitor_create::tests::monitor_prompt_constrains_task_description_previews` asserts that the daemon prompt contains the new description rules and source-prefix exclusions.
