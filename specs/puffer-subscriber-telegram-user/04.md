# puffer-subscriber-telegram-user update 04

Adds local Telegram Desktop authentication import.

Design and behavior:

- The subscriber accepts `TelegramImportTdata` before login, during pending
  login, and while already authenticated.
- Import reads a Telegram Desktop `tdata` directory with `hermes-tdata`,
  selects the main account by default, converts it to a grammers session, and
  writes `$PUFFER_SKILL_STATE_DIR/telegram.session` atomically.
- The import persists the built-in Telegram Desktop API id/hash so subsequent
  resumes use credentials compatible with the imported authorization key.
- After writing the session, the subscriber reconnects to Telegram and emits
  the existing `login_complete` control event with `imported=true`; failures
  emit `login_error` with phase `import_local` or `import_verify`.

Contracts:

- `path` is optional and defaults to the platform Telegram Desktop `tdata`
  location.
- `account_index` is zero-based and defaults to the first account.
- `passcode` is the local Telegram Desktop app passcode, not Telegram cloud
  2FA.
- Import never writes the passcode to disk.
