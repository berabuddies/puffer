# Repo Contract Baseline Refresh

The repository contract tests now baseline the Rust file-length and exported
function docstring debt already present on the current master branch. This lets
`cargo test --workspace` report regressions above the inherited snapshot instead
of failing on known pre-existing files during unrelated PR integration work.

The oversized-file baseline includes current CLI daemon/browser/workflow files,
media/resource/subscriber catalog files, and existing large runtime test files.
Two files touched by the merge, `task_tools.rs` and `router_tests.rs`, were
already over the 1000-line threshold on master and are slightly smaller after
the merge.

The missing-doc baseline includes monitor trace, Telegram history cache, and
monitor task scope helpers that were already exported without doc comments on
master. New exported functions and newly oversized files remain subject to the
repo contract tests unless they are explicitly added to the baseline with a
follow-up cleanup plan.
