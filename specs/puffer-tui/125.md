# Workflow action toggle completions

- The TUI slash popup now offers live workflow action management completions
  for `/workflows pause`, `/workflows resume`, and `/workflows delete`.
- Pause rows are limited to enabled bindings, resume rows are limited to paused
  bindings, and delete rows remain available for every binding.
- Alias searches such as `/workflows disable ...`, `/workflows enable ...`,
  `/workflows remove ...`, and `/workflows rm ...` complete to canonical local
  commands.
- Workflow subcommand completion moved into a dedicated popup module so the
  main popup file stays below the repository line limit as the workflow command
  surface grows.
